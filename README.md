# Lesson 5 - Terraform Infrastructure Project

Проєкт демонструє створення інфраструктури на AWS з використанням Terraform з модульною архітектурою.

## Опис модулів

### 1. S3 Backend Module (`modules/s3-backend/`)

- **S3 бакет** для зберігання Terraform state файлів
- **DynamoDB таблицю** для блокування state файлів
- **Версіонування** для збереження історії змін
- **Шифрування** для захисту даних
- **Блокування публічного доступу** для безпеки

### 2. VPC Module (`modules/vpc/`)

- **VPC** з CIDR блоком 10.0.0.0/16
- **3 публічні підмережі** в різних Availability Zones
- **3 приватні підмережі** в різних Availability Zones
- **Internet Gateway** для публічних підмереж
- **NAT Gateway** для приватних підмереж
- **Route Tables** для налаштування маршрутизації

### 3. ECR Module (`modules/ecr/`)

- **ECR репозиторій** для зберігання Docker образів
- **Автоматичне сканування** образів на вразливості
- **Політику доступу** для репозиторію
- **Шифрування** для зберігання образів

## Команди для роботи з проєктом

### Ініціалізація проєкту
```bash
terraform init
```

### Перегляд плану змін
```bash
terraform plan
```

### Застосування змін
```bash
terraform apply
```

### Видалення інфраструктури
```bash
terraform destroy
```

### Перегляд вихідних даних
```bash
terraform output
```

## Налаштування

### Регіон AWS
Проєкт налаштований для роботи в регіоні `eu-central-1` (Франкфурт).

### Availability Zones
Використовуються зони:
- eu-central-1a
- eu-central-1b
- eu-central-1c

### CIDR блоки
- VPC: 10.0.0.0/16
- Публічні підмережі: 10.0.1.0/24, 10.0.2.0/24, 10.0.3.0/24
- Приватні підмережі: 10.0.4.0/24, 10.0.5.0/24, 10.0.6.0/24

## Вихідні дані

Після успішного виконання `terraform apply` ви отримаєте:

- **S3 бакет** для зберігання state файлів
- **DynamoDB таблицю** для блокування
- **VPC** з повною мережевою інфраструктурою
- **ECR репозиторій** для Docker образів

## Безпека

- Всі ресурси мають шифрування
- S3 бакет заблокований від публічного доступу
- ECR репозиторій має налаштовану політику доступу
- VPC має правильно налаштовану маршрутизацію

## Вимоги

- Terraform >= 1.0
- AWS CLI налаштований
- Відповідні права доступу до AWS
